## 一句话定义

快速排序是一种**分治**排序：选一个基准（pivot），把数组分成“比它小”和“比它大”两部分，再分别递归排序。平均 $O(n\log n)$，原地排序、常数小，但最坏情况 $O(n^2)$。

## 为什么重要

- C 标准库 `qsort`、C++ `std::sort`（内省排序 introsort 以快排为主）等大量系统级排序以它为基础。【有据可查】introsort：<https://en.wikipedia.org/wiki/Introsort>
- 是理解“分治 + 随机化”思想的经典例子；分区（partition）思想还用于快速选择第 k 小元素（quickselect）。

## 原理 / 图解

【有据可查】由 C. A. R. Hoare 于 1961 年发表（Algorithm 64: Quicksort, *Communications of the ACM*）：<https://doi.org/10.1145/366622.366644>

```mermaid
flowchart TD
    A[3 6 1 5 9 2 5<br/>选基准 5] --> B[小于 5<br/>3 1 2]
    A --> C[等于 5<br/>5 5]
    A --> D[大于 5<br/>6 9]
    B --> B1[递归排序 → 1 2 3]
    D --> D1[递归排序 → 6 9]
    B1 --> R[拼接 1 2 3 5 5 6 9]
    C --> R
    D1 --> R
```

复杂度递推：每层分区 $O(n)$；若每次大致对半分，共 $\log n$ 层：

$$
T(n) = 2T(n/2) + O(n) \Rightarrow T(n) = O(n \log n)
$$

若每次基准都是最大/最小值（如对已排序数组总选末尾），则：

$$
T(n) = T(n-1) + O(n) \Rightarrow T(n) = O(n^2)
$$

## 可运行示例

简单版与原地分区版快排，统计三种情况下的比较次数，并与内置 `sorted` 比速度（Python 3.15.0 实际运行）：

```python
# 文件：examples/19_quicksort.py
# 快速排序：选基准 pivot，分成 <pivot 和 >pivot 两部分，递归。平均 O(n log n)，最坏 O(n^2)
import random, time, sys
sys.setrecursionlimit(100_000)

def quicksort_simple(a):                       # 易读版（额外空间）
    if len(a) <= 1: return a
    p = a[len(a) // 2]
    return quicksort_simple([x for x in a if x < p]) + [x for x in a if x == p] + quicksort_simple([x for x in a if x > p])

comparisons = 0
def quicksort_inplace(a, lo=0, hi=None, pick=lambda lo, hi: hi):   # Lomuto 分区，原地
    global comparisons
    if hi is None: hi = len(a) - 1
    if lo >= hi: return
    k = pick(lo, hi); a[k], a[hi] = a[hi], a[k]
    p, i = a[hi], lo
    for j in range(lo, hi):
        comparisons += 1
        if a[j] < p: a[i], a[j] = a[j], a[i]; i += 1
    a[i], a[hi] = a[hi], a[i]
    quicksort_inplace(a, lo, i - 1, pick); quicksort_inplace(a, i + 1, hi, pick)

data = [5, 2, 9, 1, 5, 6, 3]
print("简单版:", quicksort_simple(data))
b = data[:]; quicksort_inplace(b); print("原地版:", b)

n = 3000
rng = random.Random(0)
for desc, arr, pick in [("随机数组 + 末尾作基准", [rng.random() for _ in range(n)], lambda lo, hi: hi),
                        ("已排序数组 + 末尾作基准", list(range(n)), lambda lo, hi: hi),
                        ("已排序数组 + 随机基准", list(range(n)), lambda lo, hi: rng.randint(lo, hi))]:
    comparisons = 0; quicksort_inplace(arr, pick=pick)
    assert arr == sorted(arr)
    print(f"{desc:<16} n={n} 比较次数 {comparisons:>9,}  (n log2 n≈{int(n*11.55):,}, n²/2={n*n//2:,})")

# 实际开发：直接用内置 sorted（Timsort/Powersort，稳定，O(n log n)）
big = [rng.random() for _ in range(200_000)]
t0 = time.perf_counter(); quicksort_simple(big); t1 = time.perf_counter(); sorted(big); t2 = time.perf_counter()
print(f"20 万个数：手写快排 {(t1-t0)*1000:.0f} ms vs 内置 sorted {(t2-t1)*1000:.0f} ms")
```

输出：

```text
简单版: [1, 2, 3, 5, 5, 6, 9]
原地版: [1, 2, 3, 5, 5, 6, 9]
随机数组 + 末尾作基准     n=3000 比较次数    40,892  (n log2 n≈34,650, n²/2=4,500,000)
已排序数组 + 末尾作基准    n=3000 比较次数 4,498,500  (n log2 n≈34,650, n²/2=4,500,000)
已排序数组 + 随机基准     n=3000 比较次数    38,494  (n log2 n≈34,650, n²/2=4,500,000)
20 万个数：手写快排 255 ms vs 内置 sorted 29 ms
```

- 随机数组约 4 万次比较，接近 $n\log_2 n$；**已排序数组 + 末尾基准**约 450 万次，正好是 $n^2/2$ 的最坏情况。
- 换成随机基准，最坏情况的概率变得极小，比较次数回到约 3.8 万。
- 手写 Python 快排比内置 `sorted` 慢约 9 倍：内置排序用 C 实现且算法不同（见 [[k2.algo.mergesort]]）。

## 常见误区

- **固定选第一个/最后一个当基准**：遇到有序或近乎有序的输入会退化。用随机基准或“三数取中”。
- **以为快排是稳定的**：不稳定，相等元素的相对顺序可能改变。
- **大量重复元素时退化**：用三路分区（小于/等于/大于）。
- **实际项目手写排序**：Python 里直接用 `sorted` / `list.sort`，需要按多字段排用 `key=`。

## 与 AI 开发的关系

- **Top-k 选择**：quickselect 平均 $O(n)$ 找第 k 大，是 `numpy.partition` 等的思路来源。【有据可查】`numpy.partition` 文档提及 introselect：<https://numpy.org/doc/stable/reference/generated/numpy.partition.html>
- **理解随机化算法**：随机基准用“概率”换掉“最坏输入”，与机器学习中的随机初始化、随机打乱思想相通。
- **按分数排序候选**：RAG 重排、推荐系统排序最终都调用高效的库排序。

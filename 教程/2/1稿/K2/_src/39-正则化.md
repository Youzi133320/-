# 正则化：L1、L2、Dropout 与权重衰减

@@DISCLAIMER@@

## 一句话定义

正则化是**限制模型复杂度、防止过拟合**的一类方法：在损失中加入对参数大小的惩罚，或在训练中引入随机性，让模型更依赖普遍规律而不是死记训练数据。

$$
L_{\text{总}} = L_{\text{数据}} + \lambda\, R(\mathbf{w}),\qquad
R_{\text{L2}} = \lVert \mathbf{w} \rVert_2^2,\quad R_{\text{L1}} = \lVert \mathbf{w} \rVert_1
$$

## 为什么重要

- 训练集上表现完美、测试集上一塌糊涂（过拟合）是机器学习最常见的问题之一。
- 现代大模型训练中，权重衰减、Dropout、数据增强、早停都属于正则化手段。

## 原理 / 图解

| 方法 | 做法 | 效果 |
|---|---|---|
| L2（Ridge、权重衰减） | 惩罚权重平方和 | 权重整体变小、变平滑 |
| L1（Lasso） | 惩罚权重绝对值和 | 许多权重变为**恰好 0**，自动特征选择 |
| Dropout | 训练时随机置零部分神经元，并把其余放大 $1/(1-p)$ | 防止神经元互相依赖 |
| 早停 | 验证集损失不再下降时停止 | 简单有效 |
| 数据增强 | 扩充训练数据的变化 | 最“本质”的正则 |

L2 在梯度下降中等价于每步把权重按比例缩小（这就是“权重衰减”名称的由来）：

$$
\mathbf{w} \leftarrow \mathbf{w} - \eta(\nabla L + 2\lambda \mathbf{w}) = (1 - 2\eta\lambda)\,\mathbf{w} - \eta \nabla L
$$

## 常见误区

- **正则化越强越好**：过强会欠拟合；λ 要用交叉验证选（`RidgeCV`、`LassoCV`）。
- **不标准化就正则化**：惩罚对不同尺度的特征不公平（见 [[k2.math.normalization]]）。
- **推理时忘记关 Dropout**：PyTorch 要 `model.eval()`。
- **把 Adam 的 L2 和 AdamW 的权重衰减混为一谈**：二者在自适应优化器中不等价（见 [[k2.math.optimization]]）。
- **正则化能替代更多数据**：它只能缓解，不能凭空产生信息。

## 与 AI 开发的关系

- **大模型训练**：AdamW 的 weight_decay 是标准配置；许多大模型预训练中 Dropout 设得很低或为 0，因为数据量远大于参数容量。【社区共识】
- **LoRA 本身是一种约束**：低秩限制了更新的自由度，LoRA 也有 `lora_dropout` 参数（见 [[k2.ml.peft]]）。
- **贝叶斯视角**：L2 = 高斯先验，L1 = 拉普拉斯先验（见 [[k2.math.bayes]]）。
- **微调防遗忘**：限制参数偏离原模型太远，也是一种正则思想。

## 一句话定义

对方阵 $A$，若某个非零向量 $\mathbf{v}$ 经过变换后**方向不变、只被拉伸 $\lambda$ 倍**，即 $A\mathbf{v} = \lambda\mathbf{v}$，则 $\mathbf{v}$ 是特征向量，$\lambda$ 是对应的特征值。

## 为什么重要

- **PCA 降维**：协方差矩阵的特征向量是数据变化最大的方向，特征值是该方向上的方差。
- **稳定性分析**：反复乘同一个矩阵（RNN、深层网络、迭代算法）时，最大特征值的绝对值（谱半径）决定结果是爆炸还是消失。
- 谱聚类、PageRank、优化中的 Hessian 曲率分析都用到它。

## 原理 / 图解

定义与求法：

$$
A\mathbf{v} = \lambda \mathbf{v} \iff (A - \lambda I)\mathbf{v} = \mathbf{0} \;\Rightarrow\; \det(A - \lambda I) = 0
$$

两个重要恒等式：

$$
\sum_i \lambda_i = \operatorname{tr}(A),\qquad \prod_i \lambda_i = \det(A)
$$

实对称矩阵可以正交对角化（谱定理），$Q$ 的列是互相正交的特征向量：

$$
A = Q \Lambda Q^\top,\qquad Q^\top Q = I
$$

例：$A = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}$，特征值 3 和 1，特征向量 $(1,1)/\sqrt2$ 与 $(-1,1)/\sqrt2$。

```mermaid
flowchart LR
    D[数据矩阵 X] --> C[协方差矩阵<br/>对称]
    C --> E[eigh 特征分解]
    E --> L[特征值从大到小<br/>各方向方差]
    E --> V[特征向量<br/>主成分方向]
    V --> P[投影到前 k 个方向<br/>降维]
```

【有据可查】**NumPy 2.5 起，`np.linalg.eig` 和 `eigvals` 总是返回复数数组**（此前取决于特征值是否恰好为实数）；对称/厄米矩阵应使用 `eigh` / `eigvalsh`，保证返回实数：<https://numpy.org/doc/stable/release/2.5.0-notes.html>

## 可运行示例

验证 $A\mathbf{v}=\lambda\mathbf{v}$、迹与行列式恒等式、谱分解还原、幂迭代、用特征分解做 PCA、谱半径对反复相乘的影响（Python 3.13 + numpy 2.5.4 实际运行）：

```python
# 文件：examples/31_eigenvalue.py
# 特征值与特征向量：A v = λ v —— 矩阵只把 v 拉伸 λ 倍，不改变方向
import numpy as np
np.set_printoptions(precision=4, suppress=True)

A = np.array([[2., 1.], [1., 2.]])
vals, vecs = np.linalg.eig(A)
print("eig 返回的 dtype:", vals.dtype, "（NumPy 2.5 起 eig 总是返回复数类型，实对称矩阵建议用 eigh；这里取 .real）")
vals, vecs = vals.real, vecs.real
print("特征值:", vals)
for lam, v in zip(vals, vecs.T):
    print(f"  λ={lam:.1f}, v={v}, A@v={A@v}, λ*v={lam*v}, 相等: {np.allclose(A@v, lam*v)}")
print("特征值之和 =", vals.sum(), "= 迹", np.trace(A), "| 特征值之积 =", round(vals.prod(), 4), "= 行列式", round(np.linalg.det(A), 4))

# 对称矩阵：用 eigh（更快更稳），特征向量两两正交，可分解 A = Q Λ Qᵀ
w, Q = np.linalg.eigh(A)
print("Q Λ Qᵀ 还原 A:", np.allclose(Q @ np.diag(w) @ Q.T, A), "| Q 正交:", np.allclose(Q.T @ Q, np.eye(2)))

# 幂迭代：反复乘矩阵，向量会转向最大特征值方向（PageRank 的思想）
v = np.array([1., 0.])
for i in range(20): v = A @ v; v /= np.linalg.norm(v)
print("幂迭代 20 次得到的方向:", v, "| 对应特征值估计:", round(v @ A @ v, 6))

# PCA：协方差矩阵的特征向量 = 数据方差最大的方向
rng = np.random.default_rng(0)
X = rng.normal(size=(500, 2)) @ np.array([[3., 0.], [0., 0.5]]) @ np.array([[np.cos(0.5), -np.sin(0.5)], [np.sin(0.5), np.cos(0.5)]]).T
Xc = X - X.mean(axis=0)
C = Xc.T @ Xc / (len(X) - 1)
w, V = np.linalg.eigh(C)
order = w.argsort()[::-1]
print("协方差特征值（各主成分方差）:", w[order], "| 第一主成分解释方差比:", round(w[order][0] / w.sum(), 4))
print("第一主成分方向:", V[:, order[0]], "（数据被旋转了 0.5 弧度，期望约 ±[0.8776, 0.4794]）")

# 稳定性：循环神经网络中权重矩阵最大特征值 >1 会爆炸，<1 会消失
for rho in [0.9, 1.1]:
    W = rho * np.eye(2); h = np.ones(2)
    for _ in range(50): h = W @ h
    print(f"谱半径 {rho}: 乘 50 次后 ||h|| = {np.linalg.norm(h):.4g}")
```

输出：

## 常见误区

- **对称矩阵用 `eig`**：应该用 `eigh`，更快、更稳，并返回实数且按升序排列。
- **以为特征向量是唯一的**：乘以任意非零常数（包括 −1）仍是特征向量；PCA 方向的符号在不同库中可能相反。
- **非方阵求特征值**：只有方阵有特征值；非方阵用奇异值分解（SVD）。
- **假设 `eig` 结果有序**：`eig` 不保证顺序，需要自行排序。

## 与 AI 开发的关系

- **嵌入可视化与压缩**：PCA 把 768/4096 维嵌入降到 2D 查看，或降维后存储（见 [[k2.ml.sklearn]]）。
- **训练稳定性**：权重矩阵的谱半径与梯度爆炸/消失相关；正交初始化、谱归一化（spectral normalization）都基于此。【有据可查】谱归一化论文：<https://arxiv.org/abs/1802.05957>
- **LoRA 的低秩假设**：权重更新的奇异值谱衰减很快，所以低秩近似有效（见 [[k2.ml.peft]]）。
- **损失曲面**：Hessian 的最大特征值反映曲率，与可用学习率上限有关（见 [[k2.math.optimization]]）。
